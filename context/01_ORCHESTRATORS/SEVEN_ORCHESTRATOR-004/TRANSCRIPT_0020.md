1. Нажми на аватар справа сверху.
2. `Settings`.
3. В левом меню найди `Applications`.
4. Открой `Installed GitHub Apps`.
5. Найди `Claude` / `Anthropic`.
6. Нажми `Configure`.
7. Проверь, что в `Repository access` выбран `Ashraellen/SEVEN`.
8. Ниже посмотри permissions. Для записи нужны как минимум:
   - `Contents` → **Read and write**
