# SEVEN — Editorial Context Archive

This directory exists so the editor can understand how the seven-book project was conceived and how Book I: GREED evolved before and during manuscript production.

## Read order

### 1. Origins
Start with:
`context/SEVEN_VULNERABILITIES_SOURCE.md`

Then read:
`context/00_ORIGINS/`

This contains the retained GREED/SEVEN intake material and the earliest MAINMEMORYSYSTEM_018 transcript batches explicitly listed by the project's source map.

### 2. Orchestrator conversations
Then read in generation order:

1. `context/01_ORCHESTRATORS/SEVEN_ORCHESTRATOR-001/`
2. `context/01_ORCHESTRATORS/SEVEN_ORCHESTRATOR-002/`
3. `context/01_ORCHESTRATORS/SEVEN_ORCHESTRATOR-003/`
4. `context/01_ORCHESTRATORS/SEVEN_ORCHESTRATOR-004/`

Within each directory, read `TRANSCRIPT_INDEX.md` first, then transcript batches in numerical order.

## Evidence warning

These files preserve the strongest available conversation record, but not every historical interval is guaranteed to be verbatim-complete.

Where an original transcript index marks a gap, recovery interval, mixed evidence, or unavailable exact wording, that warning is authoritative and must remain visible.

Do not silently reconstruct missing dialogue.

`TRANSCRIPT != CANON`
`RECOVERY != VERBATIM TRANSCRIPT`
`PROPOSED != ACCEPTED`
`EDITOR INTERPRETATION != AUTHOR ACCEPTANCE`

## Why this is public

The purpose is editorial immersion: the editor should be able to see not only the current prose, but also the author's intentions, abandoned ideas, competing formulations, structural doubts, and the reasoning that produced Book I.

The archive may therefore contain ideas that were later rejected, superseded, or never canonized. Treat it as development history, not a flat canon document.

## Scope boundary

This mirror includes the SEVEN/GREED origin sources and the SEVEN ORCHESTRATOR conversation lineage.

GIAS remains a separate project. GIAS material is not automatically part of SEVEN editorial context unless separately added with explicit provenance.
