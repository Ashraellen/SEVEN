# EDITOR GUIDE — SEVEN / Book I: GREED

## Purpose

This repository gives the external editor a clean reading and editing surface without exposing the internal production/recovery/workflow repository.

## Read first

Use `editor/Current/` for the manuscript currently under editorial review.

Use `archive/PreFinal/` only when you need to compare earlier versions.

## Editing workflow

Preferred workflow:

1. Create a branch from `main`.
2. Edit the relevant file(s) under `editor/Current/`.
3. Keep changes literary/editorial: prose, rhythm, clarity, continuity, character voice, repetition, scene structure, plausibility.
4. Do not silently rewrite factual/story canon that is not supported by the text.
5. Open a Pull Request describing:
   - what changed;
   - why;
   - any continuity or structural concern;
   - any question for the author.
6. The author reviews the proposal.
7. Accepted editorial changes are then brought back into the internal APM workflow and pass the normal AUTHOR gate.

## Important boundaries

- `EDITOR COMMENT != CANON`
- `EDITOR CHANGE != ACCEPTED`
- `PUBLIC MIRROR != SOURCE OF TRUTH`
- `PRE-FINAL != FINAL`

The editor is encouraged to challenge weak prose, pacing, repetition, logic, characterization, and structure. The editor should not assume that the latest numbered version is automatically author-accepted; see `editor/STATUS.md`.
