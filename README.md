# SEVEN — Editorial Mirror

Public editorial mirror for the SEVEN fiction project.

## Where the editor should work

- `editor/Current/` — one current working version per section. **Start here.**
- `archive/PreFinal/` — complete PreFinal version history copied from the internal APM repository.
- `EDITOR_GUIDE.md` — review and change workflow.
- `editor/STATUS.md` — current acceptance/status boundary.

## Authority rule

This repository is an editorial mirror, not the project source of truth.

`PUBLIC MIRROR != CANON`
`EDITOR PROPOSAL != AUTHOR ACCEPTANCE`
`PRE-FINAL != FINAL`

The internal APM repository remains the authoritative project/provenance store.

Editor changes should be proposed through a branch / pull request whenever possible, so the author can review every change before it is brought back into the internal project.
